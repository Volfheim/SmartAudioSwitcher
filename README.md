# Smart Audio Switcher

**Smart Audio Switcher** — это удобная системная утилита для Windows, предназначенная для быстрого переключения устройств вывода и ввода звука, а также управления медиа.

Программа висит в системном трее и предоставляет современный, красивый интерфейс для управления звуком прямо на лету!

## 🚀 Основные возможности

* **Умное переключение звука**: Мгновенно переключайтесь между наушниками, колонками и другими аудиоустройствами без необходимости заходить в системные настройки Windows.
* **Глобальные горячие клавиши**:
  * `Alt + P` — Play / Pause (Старт / Пауза)
  * `Ctrl + Left` — Предыдущий трек
  * `Ctrl + Right` — Следующий трек
  * Все сочетания можно переназначить в настройках!
* **Современный UI**: Темная тема, стильный интерфейс системного трея и прозрачный оверлей микрофона.
* **Индикатор микрофона (Оверлей)**: Аккуратный полупрозрачный индикатор в углу экрана, который показывает, когда микрофон выключен.
* **Автообновление (OTA)**: Программа сама проверяет наличие новых версий на GitHub при каждом запуске и предлагает обновиться нажатием одной кнопки. Больше никаких ручных скачиваний!

## 📥 Установка

1. Перейдите на вкладку [Releases](https://github.com/Volfheim/SmartAudioSwitcher/releases).
2. Скачайте `SmartAudioSwitcher.exe` (Light версия, занимает пару мегабайт, требует установленного .NET 8) или `SmartAudioSwitcher_Full.exe` (полная версия, запустится на любом ПК без дополнительных установок).
3. Запустите программу. Установка не требуется — утилита полностью портативная.

## ⚙️ Настройки

Все настройки сохраняются локально. В окне настроек вы можете:
- Выбрать основные и альтернативные устройства вывода/ввода.
- Переназначить любые горячие клавиши.
- Настроить поведение автообновления и оверлея.

## 🛠️ Стек технологий
- C# 12 / .NET 8.0
- WPF (Windows Presentation Foundation)
- NAudio & CoreAudio API
